# Архив автономного workflow Codex/OpenCode

Этот каталог содержит неактивную историческую governance для provenance и возможного восстановления в будущем.

Комплект представляет прежнюю модель, в которой автономный editor выполнял уровни 1–4, применял уровень 5, повторял циклы review/edit и передавал кандидата отдельным fresh-review агентам OpenCode.

Архивные source files являются точными копиями. Их нельзя редактировать ради соответствия текущим именам, путям или ролям.

Комплект заменён активными источниками:

- root [`AGENTS.md`](<../../../AGENTS.md>);
- [`governance/codex-execution.md`](<../../codex-execution.md>);
- [`governance/web-review/`](<../../web-review/>);
- [`governance/repository-rules.md`](<../../repository-rules.md>).

Не загружать архивные `opencode.jsonc`, `.opencode/agents/**` или `_templates/**` как текущие инструкции.
