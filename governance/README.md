# Governance

Активная схема работы репозитория:

```text
User → ChatGPT Web → Codex → GitHub → ChatGPT Web
```

## Активные источники

- [`repository-rules.md`](<./repository-rules.md>) — текущие инварианты уровня репозитория.
- [`codex-execution.md`](<./codex-execution.md>) — ограниченный execution contract для Codex.
- [`web-review/`](<./web-review/>) — методология структуры, содержания и качества, принадлежащая ChatGPT Web.

ChatGPT Web выполняет смысловой анализ, исследование, проектирование текста и review. Для содержательных текстовых задач Web до исполнения подготавливает точный кандидат.

Codex применяет этот кандидат или другой точный bounded change-set, выполняет только применимые механические проверки, а затем делает commit и push, когда это явно предписано.

GitHub является фактическим доказательством опубликованного состояния. Отчёт Codex не доказывает, что в репозитории находится ожидаемый текст.
