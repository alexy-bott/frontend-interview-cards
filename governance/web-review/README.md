# Правила карточек для ChatGPT Web

Эти файлы являются активной смысловой методологией ChatGPT Web.

Они не являются автономным agent workflow для Codex.

## Существующая карточка

1. Прочитать actual live card и необходимый repository context.
2. Применить [`01-file-structure.md`](<./01-file-structure.md>).
3. Применить [`02-block-structure.md`](<./02-block-structure.md>).
4. Применить [`03-content-distribution.md`](<./03-content-distribution.md>).
5. Применить [`04-content-quality.md`](<./04-content-quality.md>).
6. Спроектировать точный кандидат по [`05-change-design.md`](<./05-change-design.md>).
7. Завершить применимый Web-review до исполнения Codex.
8. После push сопоставить actual GitHub result с одобренным кандидатом и выполнить repository checks.

## Новая карточка

Начать с [`new-card-workflow.md`](<./new-card-workflow.md>), затем применить тот же процесс точного кандидата и review.

## Канонический workflow

[`00-workflow.md`](<./00-workflow.md>) определяет ownership, статусы, identity кандидата, fresh Web review и границу между Web и Codex.
