# Стиль материалов для GitHub

Служебный шаблон фиксирует структуру публичных Markdown-страниц. Он не добавляется в навигацию репозитория.

## Карточка

```md
# Краткое название темы

<!-- верхняя навигация генерируется автоматически -->

## Вопрос

<br>

 💬 **Главный вопрос карточки?**

<h2></h2>

<br>
<dl>
<dd>

Основной ответ виден сразу. Заголовок или подпись «Ответ» не нужны.

</dd>
</dl>
<br>


## Дополнительные вопросы

<details>
<summary><strong>Дополнительный вопрос?</strong></summary>

<dl>
<dd>
<h2></h2>

Ответ раскрывается по клику обычным цветом текста.

<h2></h2>
</dd>
</dl>

</details>
```

- В H1 используется читаемое название без номера файла.
- Главный ответ всегда открыт; дополнительные ответы свёрнуты.
- Значок `💬` выделяет главный вопрос.
- `<dl>/<dd>` создаёт вложенный отступ для основного и дополнительных ответов.
- Пустые `<h2></h2>` создают тонкие верхние и нижние разделители.
- `<br>` задаёт дополнительные вертикальные интервалы вокруг главного блока.
- Фон и пользовательский CSS не применяются: GitHub не гарантирует их поддержку в Markdown.

Обычные таблицы размещаются непосредственно под заголовком, без обёртки `[!NOTE]`.

Раздел `Связанные темы` содержит не меньше двух смысловых ссылок на другие карточки. Текстовые заглушки, ссылки на текущую карточку и повторяющиеся цели не используются. На каждую карточку должна вести хотя бы одна тематическая ссылка из другой карточки.

## Страница раздела

- H1 совпадает с названием раздела.
- Ссылки на карточки объединяются в смысловые группы.
- Возврат ко всем разделам, количество карточек и переход к первой карточке создаёт генератор.

## Главная страница

- Короткое описание базы.
- Один широкий блок маршрутизации по всем разделам.
- Без поиска, инструкции по использованию и служебных команд.

## Правила поддержки

- Навигацию между карточками и страницы разделов не редактировать вручную.
- После изменений запускать `python scripts/generate_navigation.py` и `python scripts/generate_navigation.py --check`.
- Не добавлять подписи «Ответ», если роль текста понятна из структуры.
- Каждый пункт в разделе `Связанные темы` должен вести на существующую карточку.
